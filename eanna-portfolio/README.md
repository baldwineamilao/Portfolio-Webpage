# Eanna Baldwin H. Eamilao — Portfolio

Responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages
1. Create a GitHub repository such as `eanna-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and open the generated Pages URL.

## Customize
Replace the GitHub URL in `index.html` with your own profile URL. Update your project descriptions, links, email, LinkedIn, and skills as needed.
